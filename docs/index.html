Ohr HaChaim

Support page for the offline Ohr HaChaim reader. The commentary is the original Hebrew. The app does not translate it.

The text is stored in the app. Reading, search, history, and favourites work without a network connection. Settings stay on the device.

This project is not distributed through the App Store from this page. To build it, clone dberrebi/OhrHachaim and open the Xcode project. Questions and problems can be reported on the issue tracker.

אור החיים

דף תמיכה לקורא אור החיים הלא־מקוון. הפירוש הוא המקור העברי, בלי תרגום.

הטקסט שמור בתוך האפליקציה. קריאה, חיפוש, היסטוריה ומועדפים פועלים בלי חיבור לרשת. ההגדרות נשארות במכשיר.

הדף הזה אינו מפיץ את האפליקציה בחנות. כדי לבנות אותה, יש לשכפל את dberrebi/OhrHachaim ולפתוח את פרויקט Xcode. דיווח על בעיה נעשה במעקב הנושאים.
